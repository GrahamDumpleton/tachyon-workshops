# The price of an exception

Measure the time a program spends under an exception with Tachyon's
exception mode, on a date parser that tries one format after another:
what the mode counts, why raising is cheap and the handler is not, and
the profile before and after the fix.

About fifteen minutes, in a JupyterLab terminal. The ninth of the
**Profiling with Tachyon** workshops; it assumes you have run the
profiler once and can read its table.
