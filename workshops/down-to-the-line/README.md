# Down to the line

Paint a Tachyon profile onto the source code with the heatmap, on a
report whose slow function is twenty lines long and slow on one of
them: the index of files, the page per file, self and total time, the
hot-only filter, and the same file before and after the fix.

About fifteen minutes, in a JupyterLab terminal with the heatmap open
in tabs beside it. The fifth of the **Profiling with Tachyon**
workshops; it assumes you have run the profiler once and can read its
table.
