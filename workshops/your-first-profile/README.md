# Your first profile

Run Tachyon, the sampling profiler that ships in Python 3.15, on a
small report generator that takes longer than it should, and read the
table it prints: what a sample is, why time is samples multiplied by an
interval, why one function can fill two rows, and which function is
eating the time.

About fifteen minutes, in a JupyterLab terminal with the program open
beside it. The first of the **Profiling with Tachyon** workshops; it
assumes Python and a terminal and nothing about profiling.
