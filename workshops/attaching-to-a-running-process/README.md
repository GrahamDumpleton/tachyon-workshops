# Attaching to a running process

Profile a web application that is already running, without
restarting it, with Tachyon's `dump` and `attach`: a snapshot of
every thread's stack, and a flame graph of fifteen seconds of a
server that never knew. Who the kernel lets read a process, how to
find out what your machine allows, and what to do where it is
refused.

About fifteen minutes, in three JupyterLab terminals with the flame
graph opened beside them. The sixth of the **Tachyon on real
applications** workshops; it assumes you can read a flame graph. The
workshop finds out whether the machine allows attaching and follows
one of two paths, so it can be taken anywhere the others can.
