# Record now, look later

Record a Tachyon profile once in the compact binary format and turn it
into a table, a flame graph and a heatmap afterwards with `replay`.
Then the formats for other tools: the gecko file the Firefox Profiler
reads, JSONL for your own scripts and the pstats file, and what each
output is for.

About fifteen minutes, in a JupyterLab terminal with the pictures open
in tabs beside it. The sixth of the **Profiling with Tachyon**
workshops; it assumes you have run the profiler once and have seen its
table, and says what a flame graph and a heatmap are in a sentence
each.
