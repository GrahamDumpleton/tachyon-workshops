# A Flask application under load

Profile a web application with Tachyon: a small Flask site started
under the profiler for a fixed time and sent requests from a second
terminal. What is different about profiling a server, what the flame
graph of one looks like, thread by thread, and what wall-clock and
CPU time each say about it.

About twenty minutes, in two JupyterLab terminals with the flame
graphs opened beside them. The first of the **Tachyon on real
applications** workshops; it assumes you know what a sample is and
can read a flame graph.
