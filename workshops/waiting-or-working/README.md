# Waiting or working?

Find out whether a slow program is computing or waiting, with
Tachyon's wall-clock and CPU modes, on a feed reader that fetches from
a slow server and then merges what it fetched: what each mode keeps,
why the two tables disagree, and what the disagreement says about the
fix.

About fifteen minutes, in two JupyterLab terminals, one for a local
feed server and one for the profiler. The seventh of the **Profiling
with Tachyon** workshops; it assumes you have run the profiler once
and can read its table.
