# Reading a process from the outside

How Tachyon sees the call stack of another process without running any
code in it, why that needs permission on most systems, why the profiler
and the program must be the same Python, and what the error rate and
the blocking option mean. Includes a one-shot `dump` of a running
program, where the platform allows it.

About fifteen minutes, in a JupyterLab terminal. The third of the
**Profiling with Tachyon** workshops; it assumes you have run the
profiler once and read its table.
