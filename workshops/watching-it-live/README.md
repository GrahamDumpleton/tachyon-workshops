# Watching it live

Watch where a program spends its time while it runs, with Tachyon's
live mode, on a report that is rebuilt over and over: how to read
the display and drive it from the keyboard, and then how many
samples are enough, with the rate and duration options and the
statistics that say whether the profiler kept up.

About fifteen minutes, in a JupyterLab terminal. The last of the
**Profiling with Tachyon** workshops; it assumes you can read the
profiler's table.
